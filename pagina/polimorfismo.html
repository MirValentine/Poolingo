¿Qué es el Polimorfismo?

El polimorfismo significa "muchas formas". En programación, permite que un mismo método o acción se comporte de manera diferente dependiendo del objeto que lo use.

¿Para qué sirve?

Nos ayuda a escribir código más flexible y reutilizable. Gracias al polimorfismo, diferentes clases pueden tener métodos con el mismo nombre, pero que se ejecutan de manera distinta.

Ejemplo en la vida real

Clase: Animal

  • Todos los animales hacen un sonido.

Clases hijas:

  • Perro → hace “guau”
  • Gato → hace “miau”

Ejemplo en código (Python)

class Animal:
    def hacer_sonido(self):
        pass

class Perro(Animal):
    def hacer_sonido(self):
        return "Guau"

class Gato(Animal):
    def hacer_sonido(self):
        return "Miau"

# Uso de polimorfismo
animales = [Perro(), Gato()]

for animal in animales:
    print(animal.hacer_sonido())
# Salida:
# Guau
# Miau

Conclusión

El polimorfismo permite que diferentes clases usen un mismo método, pero que cada una lo ejecute a su manera. Esto hace que los programas sean más dinámicos y fáciles de expandir.
