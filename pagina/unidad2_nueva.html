1.1 Tipos de datos: variables y operaciones básicas

¿Que es una variable?

Variable

Una variable es un espacio en la memoria donde un programa guarda un dato que puede cambiar durante la ejecución. Cada variable tiene un nombre que sirve para identificarla y acceder a su valor cuando sea necesario.

Las variables sirven para guardar y recuperar datos, representar valores existentes y permitir asignarles valores nuevos cuando sea necesario. También permiten que los programadores se refieran a un dato usando un nombre representativo, en lugar de recordar el valor directamente, lo que facilita el desarrollo y comprensión de programas más complejos.

Reglas básicas para nombrar y declarar variables

Las variables deben cumplir con ciertas características y reglas para poder declararse correctamente dentro de un programa. Estas reglas aseguran que el código sea claro, ordenado y que la computadora pueda interpretar sin errores los nombres y valores que se les asignan.

  • Identificador: Es el nombre de la variable dentro del programa.
  • Sin espacios: No se permiten espacios en el nombre.
  • No iniciar con un número: Ejemplo: edad1 ✔️, 1edad ❌
  • No usar palabras reservadas: Como if, else, while, etc.
  • Mayúsculas y minúsculas importan: total y Total son variables distintas.
  • Declaración obligatoria: Antes de usar una variable, se debe declarar su tipo, nombre y opcionalmente el valor inicial.

¿Cómo se declara una variable?

tipo nombre = valor;

Ejemplos en Java

int edad = 20;
String nombre = "Luis";
double precio = 19.99;
boolean activo = true;

Tipos de dato

Cuando programamos, necesitamos guardar información dentro de variables: números, palabras, valores verdaderos o falsos, e incluso datos más complejos. Para que la computadora sepa qué tipo de información va a almacenar cada variable, es necesario indicar el tipo de dato.

Los tipos de datos funcionan como categorías que le indican al programa qué tipo de valores puede almacenar una variable, cuánta memoria debe reservar para guardarlos y qué operaciones están permitidas con ellos. Gracias a estas categorías, el lenguaje de programación puede interpretar correctamente la información y evitar errores al momento de ejecutar el código.

En Java (y en la mayoría de lenguajes), los tipos de datos se dividen principalmente en:

  • Datos numéricos: Incluyen valores enteros y decimales que se utilizan para realizar operaciones matemáticas.
  • Datos de texto: Representan caracteres y cadenas de palabras que permiten almacenar nombres, mensajes y cualquier información escrita.
  • Datos lógicos: Se limitan a dos valores posibles, true o false, y se emplean para tomar decisiones dentro de un programa.

Java utiliza diferentes tipos de datos según la información que necesitemos almacenar. Estos son los más comunes:

  • int: Representa números enteros sin decimales (por ejemplo: 5, 120, -3).
  • double: Representa números decimales con precisión (por ejemplo: 3.14, 8.75).
  • char: Almacena un solo carácter entre comillas simples (por ejemplo: 'A', '7').
  • String: Representa texto, como palabras o frases completas.
  • boolean: Solo puede almacenar verdadero o falso (true / false).

Operaciones Básicas con Variables (Aritmética)

Una vez que declaramos y asignamos un valor a una variable, podemos usarla para realizar cálculos. En Java, utilizamos los siguientes operadores aritméticos:

Operador Nombre Ejemplo con Variables Resultado
+ Suma (Adición) int a = 5; int b = 3; int suma = a + b; 8
- Resta (Sustracción) int a = 5; int b = 3; int resta = a - b; 2
* Multiplicación int a = 5; int b = 3; int producto = a * b; 15
/ División int a = 5; int b = 3; int cociente = a / b; 1 (División entera)
% Módulo (Residuo) int a = 5; int b = 3; int residuo = a % b; 2

Concepto clave: División Entera

Cuando trabajamos con variables de tipo entero tipo entero (int), el operador de división (/) ignora la parte decimal. Si necesitas obtener un resultado con decimales, al menos una de las variables o el resultado deben ser de tipo double.

Clase y objeto

¿Que es una clase y un objeto?

En la unidad anterior, aprendiste a manejar variables como contenedores individuales para almacenar datos. Sin embargo, en la Programación Orientada a Objetos (POO), necesitamos una forma de agrupar esos datos y el comportamiento relacionado

La respuesta a esta necesidad son las Clases y los Objetos.

Una Clase es una especie de plantilla para crear objetos de forma ya predefinida. Las Clases sirven para representar conceptos o entidades del mundo real (como un "Estudiante" o una "Cuenta Bancaria"). Cada objeto creado a partir de una Clase ahora será una instancia de esa Clase, una parte fundamental de POO.

Cada objeto tiene dos características fundamentales que lo definen:

  • Estado (Atributos): Son los datos específicos que el objeto tiene en un momento dado. Un objeto almacena los valores de las variables definidas en la Clase.
    Ejemplo: Si la clase es Coche, un objeto llamado miCoche tendrá los atributos: color = "Rojo", marca = "Toyota", velocidad = 50.
  • Comportamiento (Métodos): Son las acciones que el objeto puede realizar. Los métodos son compartidos por todos los objetos de la misma clase.
    Ejemplo: El objeto miCoche puede usar los métodos definidos en la clase, como acelerar(), frenar() o encender().

Creación de Objetos: La Instanciación

Una vez que tienes el plano (la Clase), el proceso de crear un Objeto real y funcional a partir de ese plano se llama instanciación.

En Java, la instanciación se realiza usando la palabra reservada new y llamando al Constructor de la clase. El constructor es la "fábrica" que inicializa el objeto.

Sintaxis de Instanciación

La línea de código para crear un objeto se divide en tres partes:

ClaseNombre nombreObjeto = new ClaseNombre();

  • Declaración: Especificas el tipo de dato (`ClaseNombre`) y el nombre de tu variable objeto.
  • Palabra clave `new`: Indica al sistema que reserve memoria para el nuevo objeto.
  • Constructor: La llamada a `ClaseNombre()` ejecuta el método constructor de la clase para inicializar el objeto.

Ejemplo Práctico: Creando un Coche

Si tenemos la Clase `Coche`, así creamos un Objeto llamado `miCoche`:

Coche miCoche = new Coche();

Ahora, la variable miCoche contiene la referencia a un objeto `Coche` recién creado en la memoria.

Constructores: Inicializando el Objeto

La Instanciación (que acabamos de ver con la palabra clave new) es solo la mitad del proceso de creación. El Constructor los constructores en Java deben tener el mismo nombre que la clase y no tener un tipo de retorno. Su objetivo primario es asignar valores iniciales a las variables de instancia del objeto.

Características Clave del Constructor

  • **Mismo Nombre:** Debe llamarse exactamente igual que la Clase.
  • **Sin Retorno:** No tiene tipo de retorno, ni siquiera void.
  • **Llamada Implícita:** Se invoca automáticamente cuando usamos new ClaseNombre().

1.2. Encapsulación: Implementación con Modificadores de Acceso

La **Encapsulación** es el pilar de POO que nos permite proteger los datos de un objeto. Para implementar esta protección, Java utiliza los Modificadores de Acceso.

Concepto Clave: Ocultamiento de Información

El objetivo es ocultar los **Atributos** para que solo se pueda acceder a ellos a través de los **Métodos** controlados que definimos.

Modificadores de Acceso: La Herramienta de Control

Estos modificadores dictan la visibilidad de los elementos (atributos y métodos) de una clase:

Modificador Concepto Rol en la Encapsulación
private Restringido: Solo visible y accesible dentro de su propia Clase. Se usa para los **atributos** (los datos) para protegerlos.
public Universal: Visible y accesible desde cualquier parte del programa. Se usa para los **métodos** (comportamiento) que deben ser la interfaz pública del objeto.

Getters y Setters: La Interfaz Segura

La **Encapsulación Correcta** se logra al:

  • Declarar todos los **atributos** como private.
  • Proporcionar **Métodos Getters y Setters** declarados como public.

Ejemplo: Encapsulación en la Clase Persona

public class Persona {
    // 1. Atributo oculto (private)
    private int edad; 

    // 2. Método Setter (public) para modificar con VALIDACIÓN
    public void setEdad(int nuevaEdad) {
        if (nuevaEdad > 0) { // Validación: Edad debe ser positiva
            this.edad = nuevaEdad;
        } else {
            System.out.println("Error: Edad no válida.");
        }
    }

    // 3. Método Getter (public) para leer
    public int getEdad() {
        return this.edad;
    }
}
