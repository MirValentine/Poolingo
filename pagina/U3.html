Unidad 3: Implementación y Pruebas

En esta unidad pasarás del diseño a la construcción del programa. Aprenderás cómo implementar lógica, trabajar con arreglos, usar colecciones, recorrer datos y comprobar que el código funciona correctamente.

  • Aplicarás estructuras de control para tomar decisiones y repetir procesos.
  • Identificarás cuándo usar arreglos de una o dos dimensiones.
  • Comprenderás el uso de iteradores y colecciones.
  • Reconocerás la importancia de probar y documentar el código.

3.1 Control del flujo del programa

Las estructuras de control permiten decidir qué instrucciones se ejecutan y cuántas veces se repiten. Son esenciales para dar lógica al programa.

EstructuraUsoEjemplo
if / elseTomar decisionesValidar si un usuario aprobó
forRepetir con contadorRecorrer 10 posiciones
whileRepetir mientras se cumpla una condiciónSolicitar contraseña hasta que sea correcta
 
int calificacion = 85;
if (calificacion >= 60) {
    System.out.println("Aprobado");
} else {
    System.out.println("Reprobado");
}

3.2 Arreglos 1D y 2D

Un arreglo permite guardar varios valores del mismo tipo en una sola estructura. Los arreglos de una dimensión funcionan como una lista; los de dos dimensiones funcionan como una tabla.

Arreglo 1D: int[] edades = {18, 19, 20};
Arreglo 2D: int[][] matriz = {{1,2}, {3,4}};

3.3 Iteradores y colecciones

Las colecciones permiten guardar grupos de objetos de forma flexible. A diferencia de los arreglos, muchas colecciones pueden crecer o reducirse durante la ejecución.

ArrayList<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Luis");

for (String nombre : nombres) {
    System.out.println(nombre);
}

3.4 Pruebas y documentación

Probar el código permite encontrar errores antes de entregar el programa. Documentar ayuda a que otras personas entiendan cómo funciona y cómo darle mantenimiento.

  • Pruebas: verifican que el programa produzca los resultados esperados.
  • Depuración: ayuda a encontrar y corregir errores.
  • Documentación: explica el propósito, uso y funcionamiento del código.
