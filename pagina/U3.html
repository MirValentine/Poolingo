En esta unidad, pondremos en práctica todo lo aprendido sobre lógica de programas. Exploraremos cómo manejar grandes cantidades de datos usando **Arreglos** y **Colecciones** de manera eficiente, y cubriremos las bases para crear código robusto y bien documentado.

3.1 Programas con Estructuras de Control

Las estructuras de control (**if/else, for, while**) son la columna vertebral de la lógica. En la práctica, estas estructuras se combinan y anidan para resolver problemas complejos, como iterar sobre datos y tomar decisiones en cada paso.

Anidamiento (Nesting)

Es la práctica de colocar una estructura de control dentro de otra (ej. un if dentro de un for o viceversa) para crear lógicas más precisas. Esto es clave al trabajar con arreglos bidimensionales o colecciones complejas.

Ejemplo: Bucle con Decisión


for (int i = 1; i <= 5; i++) { // Repetir 5 veces
    if (i % 2 == 0) { // Si 'i' es par
        System.out.println(i + " es un número par.");
    } else {
        System.out.println(i + " es impar.");
    }
}

3.2 Arreglos (Arrays)

Un **Arreglo** es una estructura de datos que almacena una **colección de elementos del mismo tipo** en una secuencia de memoria fija. Se accede a los elementos mediante un **índice** (posición), que siempre comienza en **cero (0)**.

Arreglos Unidimensionales (1D)

Son listas simples de elementos. Se declaran usando corchetes [].

Sintaxis 1D


// Declaración e inicialización
String[] nombres = {"Ana", "Luis", "Carlos"};

// Acceso al elemento:
System.out.println(nombres[1]); // Output: Luis

Arreglos Bidimensionales (2D - Matrices)

Son estructuras tipo matriz o tabla (filas y columnas). Requieren dos pares de corchetes [][] para su declaración y acceso. Usualmente se usa un doble bucle for para recorrerlas.

Sintaxis 2D (Matriz 2x3)


int[][] matriz = {
    {1, 2, 3}, // Fila 0
    {4, 5, 6}  // Fila 1
};

// Acceso: Fila 1, Columna 0
System.out.println(matriz[1][0]); // Output: 4

3.3 Colecciones (Arreglos Dinámicos)

A diferencia de los arreglos fijos (tamaño inmutable), las **Colecciones** permiten que el tamaño de la estructura de datos cambie dinámicamente durante la ejecución del programa. La clase más común en Java es **ArrayList**.

Ventaja Clave

El ArrayList es **dinámico**. Permite **añadir** o **eliminar** elementos fácilmente en tiempo de ejecución, a diferencia de los arreglos tradicionales cuyo tamaño se define al inicio.

Iteradores y el bucle for-each

El bucle **for-each** (también llamado bucle mejorado o *enhanced for loop*) es un tipo de iterador que simplifica el proceso de recorrer colecciones y arreglos, enfocándose solo en los elementos y no en el manejo manual de los índices.

Ejemplo: ArrayList y for-each


// 1. Crear un ArrayList 
ArrayList<String> lista = new ArrayList<>();
lista.add("Manzana");
lista.add("Pera");
lista.remove(0); // Elimina "Manzana"

// 2. Recorrer con for-each
for (String fruta : lista) {
    System.out.println("Comer: " + fruta);
}
// Output: Comer: Pera

3.4 Pruebas de Métodos y Documentación Básica

El código no solo debe funcionar, sino que debe ser comprensible y verificable. Estos dos pilares aseguran la calidad y el mantenimiento del software.

Documentación Básica (Javadoc)

Javadoc es una herramienta que genera documentación HTML de manera automática a partir de comentarios especiales en el código, usando la sintaxis /** ... */. Es esencial para explicar la función de clases, métodos y parámetros.

Ejemplo: Comentario Javadoc


/**
 * Este método calcula la suma de dos números enteros.
 * @param a Primer número entero
 * @param b Segundo número entero
 * @return La suma total de a y b.
 */
public int sumar(int a, int b) {
    return a + b;
}

Pruebas de Métodos (Testing)

Consiste en verificar que un método produce el resultado esperado para una entrada dada. Esta práctica se realiza con casos de prueba: se alimenta el método con un valor conocido y se verifica que el resultado sea el esperado. En la industria, se usan frameworks especializados como **JUnit**.

Caso de Prueba

Para probar el método sumar(a, b), un caso de prueba es: Si se llama a sumar(5, 3), la prueba verifica si la salida es **8**.
